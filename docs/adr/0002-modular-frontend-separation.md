# ADR-0002: Розділення структури інтерфейсу на HTML та CSS файли

**Статус:** прийнято

## Контекст
Необхідно забезпечити чисту організацію фронтенд-частини проєкту, щоб розмітка сторінки та її візуальне оформлення не змішувалися в одному документі.

## Рішення
Вирішено розділити інтерфейс на окремі компоненти: розмітку шапки винесено у файл `header.html`, а стилізацію — у глобальну таблицю стилів `style.css`.

## Наслідки
* **Переваги:** Покращена читабельність коду, можливість незалежно змінювати дизайн чи структуру сторінки.
* **Компроміси/Обмеження:** Потреба підключати зовнішні файли стилів та керувати шляхами до них.

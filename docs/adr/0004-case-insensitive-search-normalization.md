# ADR-0004: Регістронезалежна нормалізація вхідних даних для пошуку

**Статус:** прийнято

## Контекст
Користувачі можуть вводити запити для пошуку категорій у різному регістрі або з випадковими пробілами (наприклад, `" Електроніка "` замість `"електроніка"`), що призводило б до хибнонегативних результатів.

## Рішення
Впровадити обов'язкову нормалізацію вхідного рядка за допомогою методів `.strip()` та `.lower()` перед проведенням порівняння з базою категорій.

## Наслідки
* **Переваги:** Підвищення стійкості програми до помилок користувача, точний пошук незалежно від регістру символів.
* **Компроміси/Обмеження:** Невелике додаткове навантаження на процесор для виконання операцій очищення рядків (несуттєве для поточного обсягу даних).

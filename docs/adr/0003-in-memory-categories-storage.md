# ADR-0003: Зберігання категорій товарів у вигляді вбудованої константи

**Статус:** прийнято

## Контекст
На поточному етапі розробки прототипу повноцінна реляційна база даних є надлишковою і лише ускладнює структуру проєкту та його запуск.

## Рішення
Зберігати список доступних категорій (`CATEGORIES = [...]`) безпосередньо у пам'яті у вигляді глобальної константи в модулі `search.py`.

## Наслідки
* **Переваги:** Миттєвий доступ до даних без затримок на підключення до БД, відсутність потреби налаштовувати міграції чи зовнішні сервери.
* **Компроміси/Обмеження:** Статичність даних (додавання нових категорій вимагає зміни коду), відсутність збереження змін після перезапуску програми.

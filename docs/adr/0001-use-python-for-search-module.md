# ADR-0001: Використання мови Python для бізнес-логіки пошуку

**Статус:** прийнято

## Контекст
Проєкт вимагає реалізації простого та швидкого алгоритму фільтрації товарів за категоріями з мінімальними накладними витратами на розгортання.

## Рішення
Обрано мову програмування Python 3.x для написання модуля пошуку у файлі `search.py`.

## Наслідки
* **Переваги:** Висока швидкість розробки, прості та зручні вбудовані методи для обробки рядків і списків (`.lower()`, `.strip()`, `.append()`).
* **Компроміси/Обмеження:** Необхідність встановленого інтерпретатора Python на машині для виконання скрипту.

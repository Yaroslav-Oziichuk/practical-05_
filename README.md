# Practical 06

Це вебпроєкт, розроблений для демонстрації командної роботи в Git, верстки базових елементів сайту та реалізації логіки пошуку товарів за категоріями.

## Можливості
* **Пошук товарів:** Фільтрація каталогу товарів за визначеними категоріями (`search.py`).
* **Модульна верстка:** Готовий компонент заголовка сторінки (`header.html`).
* **Кастомні стилі:** Оформлення та адаптація елементів інтерфейсу (`style.css`).
